ABOUT THIS SPACE

把复杂问题，拆到真正理解为止。

这是一个用于沉淀技术文章和学习笔记的个人空间。 内容将主要围绕大模型推理、生成式推荐、源码阅读、系统架构和论文理解展开。

01

为什么写

写作是检验理解的方式。文章会尽量保留问题、推导和判断过程，而不只留下结论。

02

关注什么

推理调度、KV Cache、Beam Search、生成式推荐、系统设计和值得反复阅读的论文。

03

如何更新

文章以 Markdown 管理，提交到 GitHub 后由 GitHub Pages 自动构建和发布。
