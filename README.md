## 发布文章

在 `_posts/` 下创建 Markdown 文件，文件名使用：

```text
YYYY-MM-DD-article-slug.md
```

文章头部示例：

```yaml
---
layout: post
title: "文章标题"
description: "文章摘要"
date: 2026-07-24
category: "vLLM 源码"
tags: [vLLM, Scheduler]
reading_time: "约 10 分钟"
---
```

正文直接使用 Markdown 编写。提交到 `main` 分支后，GitHub Pages 会重新构建网站。
